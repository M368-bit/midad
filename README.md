# مِـــدَاد | MIDAD — المنصة الإسلامية الموثقة

> منصة إسلامية معاصرة للمعرفة والمراجع والدروس والكتب والأحاديث النبوية الصحيحة، مبنية وفق أعلى معايير الجودة البرمجية والتحقق العلمي الرصين، خالية من الاختلاق والبيانات الوهمية.

---

## 📖 1. نبذة عن المشروع

مشروع **مداد | MIDAD** يهدف إلى تقديم واجهة رقمية عصرية تليق بتراث الأمة الإسلامية، وتجمع بين:
- **الأصالة والتوثيق:** ربط كل مادة (عالم، حديث، كتاب، درس) بمرجع موثوق وقابل للتحقق المباشر.
- **التصميم المعاصر الهادئ:** هوية بصرية مريحة معتمدة على الأسود الداكن والأخضر الزمردي مع دعم كامل ومتقن للوضع الليلي والنهاري ودعم RTL للغة العربية.
- **الأمان والخصوصية:** فصل الصلاحيات عبر سياسات الأمان على مستوى السجل (Supabase Row Level Security).
- **الجاهزية للتوسع:** معمارية برمجية قابلة للربط لاحقاً بتطبيقات الجوال لنظامي Android وiOS من نفس قاعدة البيانات.

---

## 🎨 2. الهوية البصرية ونظام التصميم

- **الاسم التجاري:** مداد | MIDAD.
- **الطابع:** إسلامي معاصر، احترافي، هادئ، بسيط، وسهل الاستخدام.
- **الألوان:**
  - أسود داكن للخلفيات الليلية (`#080c14` / `#0f172a`).
  - أخضر زمردي أساسي (`#059669` / `#10b981`).
  - درجات رمادية ومحايدة للنصوص والبطاقات (`#f8fafc` / `#ffffff` في الوضع النهاري).
  - **ممنوع استخدام الذهبي:** تم الالتزام التام بعدم استخدام أي درجات صفراء/ذهبية متكلفة.
- **الخطوط:** خط القاهرة (`Cairo`) للواجهات والعناوين، وخط أميري (`Amiri`) للمتون الحديثية والقرآنية.
- **إمكانية الوصول:** دعم كامل للوحة المفاتيح، والتباين اللوني العالي، ومؤشرات التحميل والحالات الفارغة الاحترافية.

## 🛠️ 3. التقنيات الأساسية (Tech Stack)

| التقنية | الاستخدام |
| :--- | :--- |
| **Next.js 14 (App Router)** | إطار العمل الأساسي للواجهات والخادم (SSR & RSC) |
| **TypeScript (Strict Mode)** | لغة التطوير مع تفعيل فحص الأنواع الصارم بنسبة 100% |
| **Tailwind CSS** | بناء نظام التصميم الموحد والحركات الانتقالية الخفيفة |
| **Supabase PostgreSQL** | قاعدة البيانات السحابية مع امتدادات `uuid-ossp` و `pg_trgm` |
| **Supabase Auth & SSR** | إدارة الجلسات والمصادقة على جهتي الخادم والعميل |
| **Supabase RLS** | سياسات أمان صارمة لحماية المفضلة وسجلات النشاط ومنع التعديل غير المصرح |
| **Vitest** | منصة الاختبارات الآلية للوحدات وتكامل الخدمات |
| **Lucide Icons** | أيقونات عصرية خفيفة ومتناسقة |

## ⚡ 5. التثبيت والتشغيل المحلي (Quick Start)

### المتطلبات الأساسية
- **Node.js:** الإصدار 18 أو أحدث (موصى به: 20 أو 24).
- **npm:** الإصدار 9 أو أحدث.

### 1. تثبيت الحزم
```bash
npm install
```

### 2. إعداد ملف البيئة
انسخ ملف الإعدادات النموذجي:
```bash
cp .env.example .env.local
```
*(ملاحظة: المنصة تعمل محلياً بكامل ميزاتها ومحتواها الموثق تلقائياً حتى قبل إضافة مفاتيح Supabase)*.

### 3. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

## 🗄️ 6. إعداد وربط قاعدة بيانات Supabase

لربط المشروع بمشروع Supabase حقيقي وتفعيل قواعد البيانات السحابية:

1. أنشئ حساباً مجانياً ومشروعاً جديداً في [supabase.com](https://supabase.com).
2. من لوحة التحكم في Supabase، انتقل إلى **Project Settings -> API** وانسخ:
   - `Project URL`
   - `anon public key`
   - `service_role secret key`
3. الصق هذه المفاتيح في ملف `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...
   ```
4. انتقل إلى تبويب **SQL Editor** في Supabase، وافتح الملف:
   `supabase/migrations/20260101000000_midad_initial_schema.sql`
   وانقر على **Run** لتطبيق المخطط وسياسات الأمان RLS والفهارس بالكامل.

## 🧪 7. الاختبارات وفحص الأكواد (Quality & Tests)

تم تضمين اختبارات آلية شاملة تغطي:
- تطبيع النصوص العربية ومطابقة البحث مع وبدون تشكيل.

- تكامل واجهة الأحاديث النبوية المفتوحة والتحقق من جلب حديث صحيح البخاري رقم 1.

### لتشغيل الاختبارات:
```bash
npm run test
```

### لفحص جودة الأكواد (Linting):
```bash
npm run lint
```

### لبناء المشروع للإنتاج:
```bash
npm run build
```

## 🌐 8. النشر على الإنترنت (Deployment)

المشروع مهيأ ومختبر للنشر المباشر بنقرة واحدة عبر منصة **Vercel** أو أي خادم Node.js:
1. اربط مستودع GitHub الخاص بالمشروع في لوحة Vercel.
2. أضف متغيرات البيئة من ملف `.env.example`.
3. اضغط على **Deploy**. سيتم بناء وتشغيل التطبيق بنجاح تام وبأعلى درجات الكفاءة.
